# The Trader's Edge

Completely rebuild this website from scratch as a premium, 

professional trading discipline platform for elite forex 

traders. The current design looks unprofessional and generic — 

I need a high-end, polished product.

BRAND IDENTITY:

- Logo: a lion head with a Gothic-style "LEGEND" wordmark 

  (uploaded), black and white

- Color palette: deep black background (#0A0A0A / #0D0D0D), 

  off-white text (#F5F5F5), gold accent (#C9A85C / #D4AF37) 

  for CTAs, active states, progress indicators, and highlights

- Typography: a strong modern sans-serif for body/UI (e.g. 

  Inter, Sora, or Manrope), and a bold serif or the Gothic 

  style echoing the logo for headings/hero titles

- Overall feel: private members' club for serious traders — 

  disciplined, minimal, confident. Not playful, not colorful, 

  no generic SaaS look

CORE PAGES / STRUCTURE:

1. HERO / LANDING

   - Full-screen dark hero with the lion logo prominently placed

   - Bold headline about discipline being the trader's edge

   - Subtext + primary CTA (gold button) to start/join

   - Subtle background texture or glow, no stock illustrations

2. DAILY TASKS PAGE

   - Clean checklist UI for daily trading routine (pre-market 

     prep, risk rules, post-trade review, etc.)

   - Each task as a card with checkbox, gold checkmark animation 

     on completion

   - Daily progress ring or bar showing % of tasks completed

   - Streak counter (consecutive disciplined days) with a 

     flame/gold icon

   - Ability to add/edit custom daily tasks

3. JOURNAL PAGE

   - Trading journal entry form: date, pair, setup/strategy used 

     (SMC concepts: liquidity, order blocks, FVG, etc.), entry/

     exit, result, screenshot upload, notes on emotions/discipline

   - Journal history as a clean timeline or card list, filterable 

     by date/result (win/loss/breakeven)

   - Summary stats at top: win rate, total trades, avg R:R, 

     current streak — displayed in minimal stat cards with gold 

     accents

4. DASHBOARD / OVERVIEW

   - Combined view: today's tasks summary, recent journal 

     entries, consistency chart (weekly/monthly), key discipline 

     metrics

   - Calendar heatmap style view (like GitHub contributions) 

     showing disciplined vs undisciplined days

5. NAVIGATION

   - Minimal sidebar or top nav (dark, gold active-state 

     underline/highlight), icons + labels: Dashboard, Daily 

     Tasks, Journal, Progress/Stats, Settings

UI/UX DETAILS:

- Rounded cards with soft shadows/glow, subtle borders 

  (rgba white 10%)

- Smooth micro-animations on checkbox completion, streak 

  updates, and page transitions

- Fully responsive, mobile-first since most usage will be on 

  phone

- Empty states should be designed (not blank), guiding the user 

  what to do first

TONE OF ALL COPY:

- Disciplined, confident, no-fluff language

- Frame every feature around consistency and mental discipline 

  as what separates funded/profitable traders from the rest
